# افغان بازار | Afghan Bazar

نسخه‌ی آغازین قابل اجرا برای توسعه‌ی بازار آنلاین افغانستان. این بسته شامل وب‌اپ Market، پنل Admin، APIهای اولیه و مدل پایگاه داده است؛ اما هنوز محصول تولیدیِ منتشرشده نیست. OTP واقعی، درگاه پرداخت، پیام‌رسانی بلادرنگ و میزبانی باید با حساب‌های واقعی متصل و آزمایش شوند.

## فناوری
- Next.js App Router + TypeScript
- PostgreSQL + Prisma
- رابط فارسی RTL
- یک برنامه وب با مسیرهای جداگانه `/` و `/admin` و API مرکزی `/api`

## اجرا با گوشی
برای ویرایش فایل‌ها با گوشی می‌توان از ویرایشگر کد اندروید یا محیط ابری مانند GitHub Codespaces استفاده کرد. اجرای PostgreSQL و سرور محلی روی گوشی معمولاً دشوار است؛ راه ساده‌تر، اجرای پروژه در محیط ابری است.

## اجرای محلی/ابری
1. Node.js 20 یا جدیدتر و npm نصب باشد.
2. PostgreSQL ایجاد کنید.
3. از `.env.example` یک کپی با نام `.env` بسازید و `DATABASE_URL` را تنظیم کنید.
4. دستورات:
   ```bash
   npm install
   npx prisma generate
   npx prisma migrate dev --name init
   npm run dev
   ```
5. وب‌سایت در `http://localhost:3000` باز می‌شود.

## مسیرها
- `/` بازار عمومی
- `/admin` داشبورد مدیریتی (در این نسخه نمای اولیه است؛ قبل از انتشار باید احراز هویت و RBAC سروری تکمیل شود)
- `/api/health` سلامت API
- `/api/plans` فهرست اشتراک‌ها
- `/api/products` فهرست/ثبت محصولات اولیه
- `/api/otp/request` و `/api/otp/verify` چارچوب OTP؛ ارسال SMS عمداً غیرفعال است تا ارائه‌دهنده واقعی +93 تنظیم شود.

## راه‌اندازی مدیر اصلی
برای امنیت، مدیر اصلی نباید با ثبت‌نام عمومی ساخته شود. در نسخه‌ی بعدی باید اسکریپت امن seed با `OWNER_PHONE` و دعوت‌نامه‌ی یک‌بارمصرف اضافه شود. فعلاً هیچ مسیر عمومی برای اعطای نقش مدیر وجود ندارد.

## موارد ضروری پیش از انتشار
- اتصال سرویس SMS که ارسال به `+93` را عملاً پشتیبانی کند.
- پیاده‌سازی OTP هش‌شده، محدودیت درخواست، انقضا، ضد سوءاستفاده و نشست امن.
- محافظت کامل `/admin` و همه APIها با نقش و مجوز سمت سرور.
- بارگذاری امن تصاویر در Object Storage.
- تکمیل سفارش، پرداخت و بررسی callback امضاشده درگاه.
- تست امنیتی، پشتیبان‌گیری، پایش و HTTPS.
